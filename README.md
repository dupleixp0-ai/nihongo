# Nihongo

Appli pour apprendre à lire et écrire le japonais (hiragana, katakana, kanji N5–N4, grammaire, verbes, lecture,
révisions espacées, flamme d'apprentissage). Le code est dans `app/` (voir `app/README.md`).

- Développement : `cd app && npm install && npm run dev`
- Publication sur GitHub Pages : `app/docs/publication-github-pages.md`
